# GynProXD

Local-first gym & bodyweight tracker. Vite + React 19 + TypeScript + Tailwind v4 +
TanStack Router/Query + Zustand. No account, no server — your data lives in your browser,
exportable as JSON at any time.

## Run

```bash
pnpm install
pnpm dev        # http://localhost:5173
```

## Scripts

| command | what it does |
|---|---|
| `pnpm dev` | dev server |
| `pnpm build` | type-check + production build |
| `pnpm lint` | oxlint |
| `node scripts/import-free-exercise-db.mjs` | regenerate exercise list from free-exercise-db (public domain) |
